## 三个关键发现

### 1. M1 显著提升工具身份保持(+5.9pp,p<0.01)
Skeleton 格式强制模型显式写出 capability_id,消除了 M0 直接生成 TaskIR 时偶发的身份丢失。这是分层表示的**确定性收益**。

### 2. 参数提取是共同短板(M1 略差)
Exact Joint 的差异几乎完全来自参数层(args_ok% = exact_joint%):M1 在 JSON 格式下更容易遗漏参数键(1.08 vs 0.92 missing/call)。这不是分层表示的缺陷,而是参数提取作为独立神经能力的不足(8B-1C C 类错误 41% 的延续)。

### 3. 合成链无法区分模型
参数值在指令中明写 → 两者都能提取 → 天花板。要测试分层在深任务上的优势,需要参数来自**前驱工具输出**而非指令文本的链——即真正的运行时数据流。

## 结论

- **分层表示的身份保持优势已确认**(+5.9pp 在 unseen-family 上显著)
- **参数提取是瓶颈**,与分层/直接无关,是独立的模型能力短板
- **合成链的区分度为零**——下一步需要真实运行时数据流(τ³ 或带隐式参数的多步轨迹)
- 对 DAC 论文:分层编译的价值在于"工具身份保证"(compiler guarantee)+ "表示强制正确性",不在端到端参数正确率(需要训练数据改进)
