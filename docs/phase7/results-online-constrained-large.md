# Phase 7C-2: Large-Scale Typed SSA Online Decoding Evaluation

**日期**: 2026-10-09 启动,2026-10-12 完成
**基线**: `8e84561`(7C-1)→ 冻结代码 `3b3977c`
**清单**: `experiments/phase7/online_decoder_manifest.json`
**数据**: 确认集 150(**held-out-from-decoder-development, oracle-capability-conditioned**——Composer 隔离实验,提供 gold capability 块;xlam 分层抽样)× 3 种子 × 5 臂 = 2250 条 + dev-30(150 条,其中 90 条由 7C-1 导入重算)

---

## 1. 评测口径修正(Task 1,已实现并有回归测试)

- **主指标 = Valid ∧ OpSeq(E2E)**,无效程序记零(7C-1 的 OpSeq% 不要求过 Validator,不能当端到端语义正确率;advisor 重算后 G0/G1/G2 = 53.3/70.0/73.3)
- 参数键质量:固定全集分母的 E2E 指标 + 条件指标分列;配对按**策略操作过滤后**的节点序列(消除位置对齐偏差)
- 新增 E2E 指标:Skill F1(过滤后操作多重集 F1)、EXEC_ACTION Recall(计数上限)
- 安全事件率正式入表:deadlock%、FSM violation%、forced 均值
- EOS `-1` 哨兵已从 `allowed_ids` 移除(旧实现会在合法 EOS 时把 -1 混入允许集,负索引误放行一个词表位)
- 真 tokenizer 一致性测试(服务器运行):字节级解码 vs `tok.decode` 抽样对拍、特殊 token 全状态禁用、非 ASCII token 全状态禁用、**tokenize(合法程序) 逐 token 过 FSM 全通过**(端到端一致性)

## 2. 实验臂(冻结于 `3b3977c`)

| 臂 | level | 内容 |
|----|-------|------|
| G0 | 0 | 无约束贪心基线 |
| G1 | 1 | 文法 FSM + EOS 门控 + 注释上限(800) |
| G2a | 2 | G1 + defined-before-use + arity 封顶 + 重复定义强制扩展 |
| G2 | 3 | G2a + Skill ISA 类型偏好(= 7C-1 G2,仅级别常数重构) |
| G3 | 4 | G2 + 规范输入类型字面量 trie(**仅名称规范化**,不声称语义兼容) |

G3 冻结类型表:ISA 签名 ∪ 语料输入类型(Str, List[Any])∪ 规范标量,共 20 个字面量。**诚实边界**:xlam-1107 类真实不兼容(`@page: Int` vs FETCH 要 Str)不会被 G3"修好"——trie 只强制规范拼写,不假装类型正确。

## 3. 数据集

- **dev-30**(13 tbs + 17 xlam):7C-1 全部调参发生于此;G0/G1/G2(s43)结果从 7C-1 导入并按新指标重算,G2a/G3 补跑
- **确认集 150**:964 池按 来源×参考深度 分层(random.seed=20261009)
- **已知局限(明示)**:964 池全部是 xlam——全部 30 个 tbs 任务恰好都在 dev-30 里。确认集无法覆盖 tbs 分布,tbs 证据仅存在于开发集。错误类型分层不可先验计算,以来源近似(来源携带了 dev-30 的错误画像)
- all-994:确认集无严重退化后才跑,且只作描述性报告,不称 untouched

## 4. 结果

### 4.1 确认集主表(E2E% = Valid ∧ OpSeq,n=150/种子)

| seed | G0 | G1 | G2a | G2 | G3 |
|------|-----|-----|-----|-----|-----|
| s42(强) | 93.3 | 93.3 | 93.3 | 93.3 | 93.3 |
| s43(弱) | 62.7 | 77.3 | 78.7 | **80.7** | 81.3 |
| s44(强) | 92.7 | 94.0 | 94.0 | **95.3** | 95.3 |
| **均值±跨种子std** | **82.9±14.3** | **88.2±7.7** | **88.7±7.1** | **89.8±6.5** | **90.0±6.2** |
| 最差种子 | 62.7 | 77.3 | 78.7 | 80.7 | 81.3 |
| 种子极差 | **30.7pp** | 16.7pp | 15.3pp | **14.7pp** | 14.0pp |

辅助指标(合并三种子):Skill F1 0.848→0.901(G1)→0.916(G2);Param E2E 0.462→0.480→0.489;EXEC_ACTION Recall 保持(0.857/1.0);**全臂零 BROKEN(2412 对配对无一破坏)**。

### 4.2 配对统计(pooled,精确 McNemar)

| 对比 | wins/losses | p | 解读 |
|------|-------------|-----|------|
| G1−G0 | **24/0** | **<0.0001** | 通用文法约束:主效应,全部在弱种子 |
| G2a−G1 | 2/0 | 0.5 | def-use/arity:小且不显著 |
| G2−G2a | 5/0 | 0.0625 | **类型偏好:方向一致零损失,p 边缘** |
| G3−G2 | 1/0 | 1.0 | 类型名规范化:≈0(被 G2 吸收) |
| G2−G1(合计) | 7/0 | ≈0.016 | Typed SSA 相对纯文法的独立增益 |

分种子方向一致性:G2−G1 在 s43 5/0、s44 2/0、s42 0/0 —— 三种子无一处倒退。

### 4.3 dev-30(s43,开发集,对照参考)

G0 53.3 → G1 70.0 → G2a/G2/G3 73.3(G1−G0: 5/0, p=0.0625);与确认集模式一致,幅度略大(dev 含 tbs 难样本)。

### 4.4 安全与开销

- **零破坏**:所有臂、所有种子 BROKEN=0
- 死锁率:G2a 0.7-3.3%,G2 0-1.3%,**G3 14.7-23.3%**(类型 trie 过窄触发掩码死胡同,回退放行——best-effort 机制的诚实代价)
- FSM violation:仅 s43 上 0.7-3.3%
- 延迟:P50 约 1.8×(9.4s→17.3s),P95 约 2.2×;掩码有缓存,生成 token 数不变
- 强种子上约束对输出是纯 no-op(s42 五臂逐字节一致,forced≈0.01)——但这是 zero accuracy regression 而非 zero runtime overhead:P50 仍 1.8×,掩码逐步计算(优化见 7C-2.1 Task 5)

### 4.5 G3 判定(诚实负结果)

类型字面量 trie 只贡献 +0.2pp(1/0)却带来 14.7-23.3% 死锁率——**名称规范化收益已被 G2 的类型偏好吸收**。G3 不进入主线;死锁率本身是"约束过窄"的信号,若未来扩展需加宽类型表或改用软惩罚。

## 4b. 核心 findings

1. **三个被测种子上离散程度明显降低**(非普适方差主张):跨种子 std 14.3→6.5,极差 30.7→14.7pp;仅 3 个训练种子,同时均值上升 82.9→89.8。"编译器在线约束降低神经程序生成的种子敏感性"在确认集上成立,且不是靠压平强种子(强种子不降反升)。
2. **效应分层**:G1(通用文法)贡献了绝大部分(+14.7pp 弱种子 / pooled 24/0);Typed SSA(G2)提供小而方向一致的独立增益(+1.6pp pooled,7/0,p≈0.016),不能全部由类型名规范化解释(G3 吸收了规范化成分后只剩 1/0)。
3. 机制与 7C-1 诊断一致:弱种子的错误集中在序列化层,文法门控(EOS/行文法/`@` 前缀)直接回收;类型偏好再回收操作数选择错误。

## 5. Task 7 预冻结裁决

| 标准 | 结果 | 判定 |
|------|------|------|
| 1. G2 在确认集优于 G1 | pooled 7/0,p≈0.016,三种子方向一致 | ✓(边缘显著) |
| 2. E2E 语义不退化 | SkillF1/Param/ExecRec 全部持平或上升 | ✓ |
| 3. 最差种子稳定受益,强种子不损 | s43 +18.0pp,s42 持平,s44 +2.6pp,BROKEN=0 | ✓ |
| 4. 增益非类型规范化解释 | G2−G2a(纯类型偏好)5/0;G3−G2(纯规范化)1/0 | ✓ |
| 5. 延迟权衡 | 1.8× P50 换 +18pp 弱种子 E2E | ✓ |

**结论:Typed SSA 清除全部五条预冻结标准,但效应量诚实标注为"小而一致"(pooled +1.6pp,边缘显著)。**

论文定位建议(供 advisor 裁决):
- **主故事 = 系统效应**:不重训练,在线编译约束使弱种子 E2E +14.7~18pp、种子方差减半、强种子零成本——这是"神经编译器"框架的直接证据
- **G1 = 可靠工程增强**(主力效应)
- **Typed SSA constraint propagation = 编译器特有的算法贡献**,增益小但零损失、可跨种子复现;作为第二贡献点而非唯一支柱
- G3 类型规范化 = 诚实负结果(被 G2 吸收)

all-994:确认集未发现退化,满足扩量门槛;但需 ~30 GPU 时,是否执行等 advisor 决定(确认集已是主证据,994 只作描述性补充)。
