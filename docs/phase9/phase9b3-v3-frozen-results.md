## 诊断(逐例核对,非猜测)

- **实体抽取已解决**: 模型输出的姓名/邮编逐字来自指令(如
  retail_17 的 Fatima Johnson/78712)——v1 的 user-latent 假象与
  v2 的幻觉担忧均未复现;
- **失败模式 = 计划不完整**: gold 需要 3 次 get_order_details 时
  模型只计划 1 次;需要 get_product_details 时整步缺失。调用数不足
  → 双射失败 → 全指标为 0;
- **根因 = 训练多样性不足(T8 已记录)**: v3 仅 2 种模板形状/130
  任务/单域,模型学会了两种形状并正确抽取实体与绑定语法(可解析
  输出中 runtime_ref 结构存在),但覆盖不了正式测试的形状空间。
